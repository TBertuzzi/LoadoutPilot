# Loadout Pilot 1.0.0

Loadout Pilot 1.0.0 is the first stable public release.

## What it does

Configure saved Blizzard talent loadouts and equipment sets for World, Delve, Dungeon, Mythic+, Raid, and PvP. Loadout Pilot detects the current context and automatically applies the configured mapping whenever the WoW client allows it.

## 1.0.0 highlights

- Supports every Retail class and specialization.
- Per-character and per-specialization mappings.
- Automatic context detection for World, Delve, Dungeon, Mythic+, Raid, and PvP.
- Automatic talent and equipment switching through Blizzard-supported APIs.
- Combat-safe queues and transition retries.
- Robust PvP -> World recovery for both talents and gear.
- Compact adaptive status HUD.
- Custom minimap button with saved rim position.
- Manual Apply fallback.
- Optional chat notifications.
- Automatic/WoW, Brazilian Portuguese, and English language selection.
- Restore Positions control for HUD and minimap icon.

## Safety and scope

Loadout Pilot does not cast abilities or automate combat. It only manages saved player talent loadouts and equipment sets through supported Blizzard APIs and respects combat/client restrictions.
